# فضاء محطة نفطال رأس الوادي

تطبيق عربي لإدارة مناوبات محطة نفطال رأس الوادي بولاية برج بوعريريج. يتضمن دورة المناوبات 3×8، إدارة العمال والأفواج، جدولًا شهريًا قابلًا للطباعة، استعلام جدول العامل، وسجل تسليم واستلام الورديات.

## المتطلبات

- Node.js 24.12 أو أحدث وnpm.
- لتجميع Android محليًا: JDK 21، Android SDK Platform 34 وBuild Tools متوافقة.
- إعداد Firebase صالح لتسجيل الدخول عبر Facebook.

## إعداد Firebase

1. انسخ `.env.example` إلى `.env`.
2. أدخل إعدادات تطبيق Firebase Web في متغيرات `VITE_FIREBASE_*`، وبريد أو UID المسؤول في المتغيرات المخصصة لذلك.
3. فعّل Facebook ضمن Firebase Authentication، وأضف نطاق النشر الفعلي في قائمة Authorized domains لدى Firebase.
4. لا ترفع `.env` إلى Git أو تشاركه. لا يتضمن أرشيف المصدر المرفق ملف البيئة.

## تشغيل وفحص تطبيق الويب

```bash
npm ci
npm run lint
npm run dev
```

يعمل خادم التطوير افتراضيًا على `http://localhost:3000`.

لبناء نسخة الإنتاج وملفات PWA:

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

تثبيت PWA من الهاتف يتطلب نشر ملفات `dist/` على نطاق HTTPS، ثم فتح الموقع في المتصفح واختيار «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق». تُخزّن بيانات الجداول محليًا في المتصفح/الجهاز؛ لا يوفّر المشروع مزامنة قواعد بيانات بين الأجهزة.

## بناء تطبيق Android

المشروع مجهز بـ Capacitor. بعد إعداد Android SDK وملف `.env`:

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

ينتج APK التطوير عادةً في `android/app/build/outputs/apk/debug/app-debug.apk`. نسخة Debug مناسبة للتثبيت الجانبي والاختبار، وليست نسخة متجر؛ نشر Google Play يحتاج إعداد توقيع Release ومراجعة متطلبات المتجر.

## تثبيت APK على Android

انقل ملف APK إلى الهاتف وافتحه، ثم اسمح بالتثبيت من هذا المصدر عند مطالبة Android. لا يمكن تثبيته عن بُعد على الهاتف من بيئة البناء.

## ملاحظات تشغيلية

- البناء يضمّن إعدادات Firebase للعميل، لذلك يجب ضبط Authorized domains وسياسات Firebase قبل الاستخدام الفعلي.
- اختبر تسجيل الدخول عبر Facebook على نطاق النشر الفعلي وعلى جهاز Android المستهدف قبل اعتماد التطبيق في العمل اليومي.
- يحتفظ التطبيق ببيانات الجداول محليًا على الجهاز؛ احفظ نسخة احتياطية عند الحاجة ولا تعتبره نظام مزامنة مركزيًا.
